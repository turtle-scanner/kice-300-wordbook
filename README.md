# 🟡 2027 KICE 300개 핵심단어장 앱 (초고속 마스터 단어사전 & 실전 인출 앱)

2027학년도 중등임용 전문상담 수석 합격을 위한 300선 핵심 표제어 인터랙티브 웹 애플리케이션입니다.

## 📚 구성 체계
- **1교시 교육학 (100선)**: 교육과정(25) + 교육방법(25) + 교육평가(25) + 교육행정(25)
- **2교시 전공 A형 (100선)**: 진로상담(35) + 심리검사/지능/MMPI-2-RF(35) + 집단상담/성격심리/대인관계(30)
- **3교시 전공 B형 (100선)**: 가족치료(30) + 정신병리 DSM-5-TR(35) + 상담기법/행동치료/놀이치료/위기상담/학폭법령(35)

## 🏆 KICE 3단 심층 루브릭 파워하우스
1. 🏆 **[KICE 4점 만점 서술문]**: 평가원 답안지 규격 무감점 4점 표준 정답문
2. 🔍 **[핵심 메커니즘 및 학술 원리]**: 출제위원이 필수 지정하는 인과관계 및 단계별 작동 기제
3. 💡 **[시험장 1초 감별 및 합격 꿀팁]**: 유사 오답 개념과의 결정적 차이 및 함정 탈출 팁

## 🚀 주요 기능
- **🎯 1장씩 플래시카드 실전 시험 모드**: 스페이스바/엔터 키로 즉시 뒤집는 초고속 인출 훈련
- **📋 전체 300개 단어장 사전 모드**: 아코디언 방식으로 펼쳐지는 3단 만점 해설
- **🔍 실시간 초고속 검색**: 한글 초성 및 키워드 0.01초 필터링
- **🔀 랜덤 셔플 & ★ 북마크**: 취약 단어 집중 반복 복습
- **🖨️ A4 규격 자동 인쇄/PDF 저장**: 시험장 직전 휴대용 요약집 출력
- **💖 고윤정 배우 응원 사진 릴레이**: 25문항마다 자동 전환되는 수험생 맞춤 격려
